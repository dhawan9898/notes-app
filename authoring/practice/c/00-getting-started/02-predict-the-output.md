What does each expression evaluate to? `5 / 2`, `5 % 2`, `5 / 2.0`, `10 - 3 * 2`, `7 & 3`, `1 << 4`.

## Explanation

`5 / 2` = **2** (integer division); `5 % 2` = **1**; `5 / 2.0` = **2.5**; `10 - 3 * 2` = **4** (multiplication first); `7 & 3` = `0111 & 0011` = **3**; `1 << 4` = **16**.

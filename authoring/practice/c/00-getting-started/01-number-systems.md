Convert `1011 0110` (binary) to decimal and to hexadecimal. Convert decimal `200` to binary and hexadecimal.

## Explanation

`1011 0110` = 128 + 32 + 16 + 4 + 2 = **182** = **0xB6** (split into nibbles `1011` = B, `0110` = 6). `200` = 128 + 64 + 8 = `1100 1000` = **0xC8**.
